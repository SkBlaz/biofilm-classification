Features to calculate

2D images use one complete package: coverage, biomass area, object count/density, size statistics, equivalent diameter, nearest-neighbour distances, porosity and pore sizes, intensity statistics, and GLCM texture.

Segmentation and threshold QC Raw-image inference restores the saved model’s voxel dimensions, segmentation, conversion, and feature groups.

Tip: Threshold optimisation is best done on a small, representative sample of your images first. Running segmentation settings on a large batch is time-consuming, so upload a few representative images, adjust the segmentation until the QC (overlay, histogram, biomass-vs-threshold curve) looks right, then run the full batch with the chosen settings.

Multiplies the automatic cutoff. Below 1 includes dimmer signal; above 1 removes more signal.
Default 0.10 (10%). Controls where the biomass curve becomes less sensitive to threshold changes.

No masks uploaded. Same dimensions as each image; nonzero = biomass, or integer labels for objects. Name each mask like its image, optionally with _mask before the extension. Works with ImageJ, BiofilmQ, and Cellpose. Thresholding is skipped.
8-bit conversion for ImageJ tuning

Download the exact thresholding TIFF from QC and tune that image in ImageJ. Conversion uses one fixed range for the entire stack. 8-bit sources remain unchanged. OME SignificantBits defines the acquisition range when available; otherwise integer images use their storage range.

For 12-bit images stored as 16-bit TIFF without bit-depth metadata, enter 4095. This is an intensity value, not a physical unit.
Groups neighbouring biomass voxels into objects. Higher connectivity merges more readily into fewer, larger objects. Default 26; affects object count and size. Imported object labels retain their identities.
Minimum size removes noise-sized specks before mask measurements. Default 0 keeps all objects. Increase to remove noise; a high value can remove real small cells.
QC includes masks and overlays for first, middle, and top slices, a histogram, and a biomass-versus-threshold curve. Three-class labels describe intensity only, not cell state.
